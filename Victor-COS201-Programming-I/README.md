Open a terminal in the `week03` directory.

**Compile and run the calculator:**

```bash

```

**Compile and run the average calculator:**

```bash
javac AverageCalculator.java
java AverageCalculator
```

**Compile and run the item-cost program:**

```bash
javac ItemCost.java
java ItemCost
```
